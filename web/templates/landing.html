How it works

Uses the Paybill
you already have.

No tenant app. No change in how they pay. RentLoop works in the background — automatic Paybill reconciliation, instant WhatsApp alerts.

✓ M-Pesa on phone ✓ M-Pesa agent shop ✓ Bank counter ✓ ATM deposit
1

Tenant pays your Paybill

Tenant sends rent to your existing Paybill using their unit reference (e.g. 4B) as the account number. Nothing changes for them M-Pesa, agent, bank, or ATM.

2

RentLoop reconciles instantly

RentLoop matches the payment to the unit, records the amount, flags partial payments and arrears, and updates the ledger — all within 3 seconds.

3

You manage from WhatsApp

You get notified instantly. Type LIST to see who's paid. Type REMIND to nudge everyone who hasn't. Type TOTAL for the full picture. No login. No URL.

WhatsApp commands

Everything from one message

Send any command in capitals to your RentLoop number. No login. No URL. No app. Works with automatic Paybill reconciliation in the background.

LIST
All units — paid, unpaid, and partial balances for the current month. Updated in real time as payments land.
REMIND
Send a WhatsApp reminder to every unpaid and partially-paid tenant. Partial payers see exactly what they still owe.
TOTAL
Total collected vs expected this month, with outstanding balance and security deposits shown separately.
HISTORY E1
Last 3 months for any unit: amounts, statuses, arrears carried forward. Full 12-month view also available.
CLAIM … TO
Assign an unmatched Paybill payment to the correct unit. Handles wrong account references automatically.
MARK … PAID
Log a cash or bank payment manually. Recorded in the same ledger as automatic Paybill payments.
15+ commands available after you join — including ADD UNIT, REPLACE tenant, SET RENT, DEPOSIT tracking, BULK CSV upload, agent portfolio view (CLIENTS, TOTAL ALL, REMIND ALL), and full 12-month landlord history.
How Paybill matching works: When a tenant pays your Paybill, they use their unit number as the account reference. RentLoop matches that reference to the unit automatically — 4b, unit 4B, and UNIT-4B all resolve to the same unit. If a tenant uses the wrong reference, type CLAIM TXN-ABC123 TO 4B to assign it in one message.
