How it works

No app. No login.
Just WhatsApp.

Everything runs through the messaging app you already have open all day.

1

Tenant pays M-Pesa

Tenant sends rent to your existing Paybill using their unit reference (e.g. 4B) as the account number. Nothing changes for them.

2

Both get notified instantly

Within 3 seconds you receive a WhatsApp notification. The tenant gets an SMS receipt. Automatic. Every payment.

3

Manage from WhatsApp

Type LIST to see who has paid. Type REMIND to nudge everyone who hasn't. No login. No URL.

WhatsApp commands

Everything from one message

Send any command in capitals to your RentLoop WhatsApp number. No login. No URL. No app.

Daily use — these are the only three you need every month
LIST
See all units — who has paid, who hasn't, and any partial balances — for the current month
REMIND
Send a WhatsApp reminder to every tenant who hasn't paid this month. One word, done.
TOTAL
Total collected vs total expected this month, with the outstanding balance
Payment lookup
RECEIPT 4B
Resend the payment receipt for a specific unit this month
RECEIPT A1
HISTORY 4B
Last 3 months of payment records for any unit — amounts and statuses
HISTORY B1
Unit management
ADD UNIT
Add a new unit with tenant name, phone number, and monthly rent
ADD UNIT 4B John Kamau 0712345678 12500
REPLACE
Swap the tenant on a unit. All previous payment history is preserved under the unit.
REPLACE 4B Grace Auma 0745678901 12500
SET RENT
Update the expected monthly rent for a unit. Takes effect immediately for new payments.
SET RENT 4B 14000
BULK ADD
Get the CSV template to upload all your tenants at once. Up to 50 units in one file.
Payment handling
MARK … PAID
Log a cash or bank payment manually. Recorded in the same ledger as M-Pesa payments.
MARK 4B PAID 12500 CASH
CLAIM … TO
Assign an unmatched payment to the correct unit when a tenant used the wrong reference
CLAIM LHG31AA5TX TO 4B

How commands work: All commands are typed in CAPITALS. Unit references match exactly what your tenant types when paying via M-Pesa if their unit is 4B, they pay account 4B and you type RECEIPT 4B. Variations like 4b, unit 4B, and UNIT-4B all resolve to the same unit automatically. For agent commands, you can use any part of the landlord's name — LIST Wanjiku will find Sarah Wanjiku Properties.
